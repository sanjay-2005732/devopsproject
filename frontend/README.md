This directory contains reference copies of the frontend source files.
The actual served files are in src/main/resources/static/

The frontend is embedded within the Spring Boot application and served
as static content. This directory exists for organizational clarity.

Files:
- index.html     → Student Management UI (CRUD operations)
- dashboard.html → CI/CD Pipeline Monitoring Dashboard
- css/style.css  → Application styles
- js/app.js      → Frontend JavaScript logic
